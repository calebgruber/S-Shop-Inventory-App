ENHANCED QUICK LOOKUP FEATURE
==============================

FEATURES IMPLEMENTED
--------------------

1. AUTO-SEARCH ON BARCODE SCAN
   - Dashboard listens for barcode scanner input globally
   - Automatically triggers search when Enter is pressed
   - No need to click Quick Lookup button first
   - Works for all user roles

2. ITEM DETAILS MODAL WITH PHOTO
   - Shows when exact barcode match is found
   - Displays full-size item photo (up to 400px)
   - Shows "No Linked Photo" placeholder if no photo exists
   - Contains complete item information:
     * Name, barcode, description
     * Category and subcategory
     * Tracking type
     * Total and in-stock quantities
     * Location
     * Created/updated dates

3. IMAGE PREVIEWS IN SEARCH RESULTS
   - Search results table shows photo column (first column)
   - 60x60px thumbnail for each item
   - Icon placeholder for items without photos
   - Positioned to the left of quantities
   - Clickable to open full details modal

HOW TO USE
----------

Auto-Search:
1. Focus on dashboard (any element)
2. Scan barcode with scanner (or type barcode + Enter)
3. Results appear automatically

Manual Search:
1. Click "Quick Lookup" button in quick actions
2. Enter barcode or item name
3. Click Search or press Enter
4. View results with photo previews
5. Click any item to see full details

TECHNICAL DETAILS
-----------------

Barcode Scanner Detection:
- Listens for rapid character input
- 100ms timeout to distinguish scanner from typing
- Enter key triggers automatic search
- Buffer resets after timeout

Photo Handling:
- Photos stored in uploads/ directory
- Thumbnail size: 60x60px
- Full display size: max 400x400px
- Object-fit cover for consistent appearance
- Fallback for missing photos

API Response:
- Returns photo_path field for each item
- Frontend handles missing photos gracefully
- Supports all existing search functionality
