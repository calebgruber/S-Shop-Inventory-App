# Sound Files

This directory should contain the following audio files for the application's easter eggs and feedback:

## Required Files:

1. **success.mp3** - Played when a barcode is successfully scanned in pick/return mode
2. **error.mp3** - Played when an incorrect barcode is scanned
3. **meow.mp3** - Played randomly when pink mode is active
4. **whopper.mp3** - Played when the cheeseburger barcode (CHZ-BGR) is scanned
5. **bonk.mp3** - Played when clicking the red cable color block

## Where to Find These Files:

You can source these from:
- Free sound libraries like FreeSound.org
- Generate using text-to-speech for simple sounds
- Create custom audio clips

## File Requirements:

- Format: MP3
- Quality: Standard web quality (128kbps is sufficient)
- Length: 1-3 seconds for feedback sounds, up to 5 seconds for easter eggs
- Volume: Normalized to prevent overly loud playback

## Installation:

Simply place the MP3 files in this directory:
```
/assets/sounds/success.mp3
/assets/sounds/error.mp3
/assets/sounds/meow.mp3
/assets/sounds/whopper.mp3
/assets/sounds/bonk.mp3
```
