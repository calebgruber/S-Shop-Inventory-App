# Sound Files

Place your audio files in this directory:

- **success.mp3** or **success.wav** - Played when a barcode scan is successful
- **error.mp3** or **error.wav** - Played when a barcode scan fails or an error occurs

You can configure the file paths in `config.php`:
- `AUDIO_SUCCESS_PATH` - Path to success sound
- `AUDIO_ERROR_PATH` - Path to error sound

Supported formats: MP3, WAV
