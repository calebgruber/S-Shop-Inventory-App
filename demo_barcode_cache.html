Key Features

🚀 Server-Side Caching

Barcodes saved as PNG files on server. One-time generation, infinite reuse.

⚡ Bulk Generation

Generate all barcodes at once with single button click. 10-30 seconds total.

🎯 Fast Loading

Cached images load in <500ms. No API delays or timeouts.

🖨️ Reliable Printing

PDFs always include all barcode images. Perfect prints every time.

How to Use

  1. Go to Paperwork → Master Barcode List
    Navigate through the main menu
  2. Click "Generate All Barcodes" (first time only)
    This downloads and saves all barcode images to the server
  3. Wait for confirmation
    Takes 10-30 seconds depending on inventory size
  4. Page reloads automatically
    Now all barcodes are cached and ready!
  5. Click "Print All Barcodes"
    Perfect PDF with all images included

Architecture Overview

User clicks "Generate All Barcodes" ↓ AJAX POST to generate_barcodes.php ↓ Server fetches all items from database ↓ FOR EACH ITEM: ├─ Call barcodeapi.org API ├─ Receive PNG image data └─ Save to uploads/barcodes/{barcode}.png ↓ Return success message ↓ Page reloads, displays cached images ↓ When printing: └─ Load PNGs from disk (FAST!) └─ Include in PDF (RELIABLE!)
