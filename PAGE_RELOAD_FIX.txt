PAGE RELOAD FIX - IMPLEMENTATION SUMMARY

After form submission, pages reloaded but showed only navbar + title.
No content (cards, tables, etc.) visible until manual refresh.

1. Session data not being saved before PHP redirect
2. JavaScript location.reload(true) interrupting page rendering cycle

1. Added session_write_close() to redirect() function
2. Replaced location.reload(true) with window.location.href = window.location.href
